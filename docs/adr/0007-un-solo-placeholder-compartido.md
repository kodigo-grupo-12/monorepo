# El placeholder es una sola pantalla compartida y sin parámetros

Lo que todavía no tiene pantalla propia muestra una sola pantalla placeholder: los tabs Transacciones y Agente como raíz, y todo lo tocable de Cuenta empujándola. La pantalla es genérica, dice «En desarrollo», no lleva parámetros y al entrar muestra un toast con el mismo texto. Como raíz de tab no ofrece botón de atrás; empujada desde Cuenta, sí, además del gesto del sistema.

Se consideró una pantalla placeholder por sección, para poder nombrar adónde se llegó. Se descartó: duplica una pantalla que todavía no dice nada y obliga a mantener varias iguales.
