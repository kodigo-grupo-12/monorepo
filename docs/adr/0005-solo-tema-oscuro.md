# Solo el tema oscuro en el MVP

El splash, el carrusel y el login se ven siempre en el oscuro de las plantillas, aunque el teléfono esté en modo claro. El fondo es el de esas imágenes. Cada pantalla conserva el verde de su propia plantilla. La paleta clara del splash no se usa. El tema claro queda para más adelante, si hay tiempo.

Se consideró seguir el modo del teléfono, como hace hoy el splash. Se descartó para el MVP: las plantillas son oscuras y el diseño tiene que coincidir con ellas.

El splash cambia de color y no de forma. Sigue siendo el icono y el crédito del grupo, ahora sobre el fondo oscuro de las plantillas.
