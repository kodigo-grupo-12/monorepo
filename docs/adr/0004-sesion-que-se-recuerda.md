# La sesión se recuerda

Quien entra con la cuenta demo deja una sesión en el aparato. Al abrir Cuéntame otra vez, el splash deja ver el inicio y el carrusel no sale. Si no hay sesión, el splash deja ver el carrusel, y de ahí se pasa al login.

Se consideró mostrar el carrusel en cada apertura, para que esa entrada se viera siempre. Se descartó: si la persona ya entró, el camino corto es el inicio.

Cerrar la sesión no entra en esta etapa. Queda para una pantalla de cuenta posterior. Hasta entonces, borrar los datos de la app vuelve a mostrar el carrusel.
