# Validación rápida con Expo Go

El bucle de desarrollo es Expo Go con el SDK 58. Un solo servidor muestra Cuéntame en el teléfono y en el navegador. No se genera la carpeta nativa de Android ni un APK. El build formal queda para cuando haya un MVP. Todavía no se decide si esa APK saldrá de Expo Build o de Android Studio.

Se consideró compilar un development build o usar Android Studio en cada cambio. Eso frena la iteración, y Expo Go de Play Store ya abre el SDK 58. Se descartó para esta etapa.
